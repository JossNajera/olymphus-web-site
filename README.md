# TESTAUTOMATE — React + Bootstrap 5

## Ejecutar

```bash
npm install
npm run dev
```

Abre la URL indicada por Vite (normalmente http://localhost:5173).

## Compilar

```bash
npm run build
```

## Archivos
- `src/main.jsx`: componentes React, navegación, servicios y formulario.
- `src/styles.css`: estilos y variables CSS.
- `public/referencia.png`: imagen original proporcionada como referencia de diseño.

## Formulario
El formulario prepara un mensaje mediante `mailto:`. No envía ni guarda datos automáticamente. Para envío directo se requiere integrar un backend o proveedor de correo.
